# Привет! 👋

Я Тахмина, системный аналитик. Делаю требования понятными, а процессы- прозрачными.  
Опыт: пет‑проекты, где я проходила полный цикл от интервью до постановки задач, диаграмм и спецификаций.

## Ключевые навыки

- **Требования и постановка:** сбор и уточнение требований, критерии приёмки, пользовательские сценарии, трассируемость.
- **Моделирование:** UML (Activity, Use Case, Sequence), BPMN; выделение ролей, статусов, условий и исключений.
- **Интеграции:** REST; JSON/XML; обработка ошибок и граничных случаев; тестирование API в Swagger.
- **Данные:** ER‑диаграммы; нормализация (до 3 НФ); ограничения; SQL‑запросы; сценарии валидации.

## Проекты (кратко)

### Спецификация требований к ПО (функция видео)
**Что сделала:** Use Case, функциональные требования, атрибуты качества, бизнес‑правила, глоссарий.  
**Результат:** команда разработки получила единый источник истины, неоднозначности сняты, ускорилась оценка задачи.

### Моделирование данных интернет‑магазина
**Что сделала:** ER‑диаграмма, нормализация до 3 НФ, словарь данных.  
**Результат:** структура базы стала консистентной, уменьшилось дублирование, появились чёткие правила валидации.

### Бэклог приложения для сети клиник
**Что сделала:** сбор требований, карта пользовательских историй, MVP, прототип в Figma, DFD (Data Flow Diagram).  
**Результат:** приоритизированный бэклог и понятная модель потоков данных- команда смогла быстрее спланировать спринт.

### Постановка задачи для стримингового сервиса
**Что сделала:** Sequence Diagram, тестирование существующего API в Swagger, описание новых операций API.  
**Результат:** спецификация готова к передаче в разработку без доуточнений, учтены граничные и негативные сценарии.
